# Pokémon Casual Teambuilder
Lets you plan your team for a casual pokemon playthrough.
- Select your game version.
- Build a team that's got a good type coverage.
- Website can suggest good pokémon that would suit your current team.
- Choose the route you want to capture the pokémon on.
- Save an infographic image with the information, so you can refer to it throughout your playthrough!
